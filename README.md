# Sanju M — Portfolio Website

Futuristic, premium portfolio built with Next.js 14, TailwindCSS & Framer Motion.

## Sections

| # | Section        | Description                                                         |
|---|----------------|---------------------------------------------------------------------|
| 1 | Splash Screen  | Animated SM monogram + loading bar (~1.6s)                          |
| 2 | Hero           | Name, title, summary, "View Experience" + "Download Resume" CTAs    |
| 3 | Top Impact     | 3 animated counters ($1K+/mo, 70% observability, 99.99% uptime)    |
| 4 | Experience     | 5 roles — timeline with expand/collapse, impact highlight badges    |
| 5 | Achievements   | 8 trophy cards with context, grouped by type                        |
| 6 | Projects       | Fraud Detection ML Pipeline — tech stack + bullets                  |
| 7 | Skills         | 11 grouped categories with individual item tags                     |
| 8 | Education      | 2 degrees with scholarship badge                                    |
| 9 | Certifications | 5 credentials with issuer info                                     |
| 10| Awards         | Smarsh Mike Pagani Scholarship spotlight                            |
| 11| Contact        | Email, phone, location, LinkedIn                                    |

## Quick Start

```bash
npm install
npm run dev
# Open http://localhost:3000
```

```For Production
npm run build

```

## Download Resume (PDF)

Click "Download Resume" → Opens a beautifully formatted HTML resume in a new tab → Click "Save as PDF" (or Ctrl+P → Save as PDF). Includes all sections: summary, experience, projects, education, grouped skills, achievements, certifications, and awards.

## Tech Stack

Next.js 14 (App Router) · TypeScript · TailwindCSS · Framer Motion · Lucide Icons · Canvas API
